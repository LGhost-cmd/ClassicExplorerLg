## Автоматизация и ограничения

В GitHub Actions сценарий test_concept98_regression.py проверяет итоговый сгенерированный исходный код по контрактам: OLE, JPEG/WebP, аватары, уведомления/счётчики, поиск и компоновка. Далее идёт компиляция MSVC Win32. Это не подмена живого GUI-сеанса: реальная приёмка всех строк таблицы возможна только на Windows с авторизованным Telegram.

При воспроизведении проблемы нужны номер теста (M-02, A-05 и т.д.), скриншот, версия из BUILDINFO.txt, файл %TEMP%\Telegacy-diagnostic.log (при необходимости удалить личные сведения); для аварийного завершения — Application Error из Windows Event Viewer.

Критерий завершения: успешный CI и реальные прогоны P0, затем P1. Без этого нельзя заявлять «абсолютная стабильность».
